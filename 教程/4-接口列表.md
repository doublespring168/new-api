# 后端接口列表

本文基于 `router/api-router.go`、`router/relay-router.go`、`router/video-router.go`、`router/dashboard.go` 整理，按功能维度列出后端暴露的主要接口。表格至少包含 HTTP 方法、API URL 和功能描述；鉴权说明根据路由中间件推断。

## 1. 接口分组总览

| 分组 | URL 前缀 | 主要功能 |
| --- | --- | --- |
| 系统公共接口 | `/api/*` | 初始化状态、系统状态、公告、协议、价格、排行榜、性能指标 |
| 用户与认证 | `/api/user/*`、`/api/oauth/*` | 注册登录、登出、OAuth、Passkey、2FA、用户自助、管理员用户管理 |
| 支付与充值 | `/api/user/*pay*`、`/api/*webhook*` | 余额充值、支付金额计算、支付回调 |
| 订阅 | `/api/subscription/*` | 订阅计划、订阅购买、用户订阅、管理员订阅管理 |
| 系统配置 | `/api/option/*`、`/api/custom-oauth-provider/*`、`/api/performance/*` | 系统 options、自定义 OAuth、性能维护、倍率同步 |
| 渠道管理 | `/api/channel/*` | AI 渠道 CRUD、测试、余额、模型拉取、多 key、上游模型更新 |
| API Token | `/api/token/*`、`/api/usage/token` | 用户令牌管理和 token 用量 |
| 日志与用量 | `/api/log/*`、`/api/data/*` | 消费日志、统计、配额数据 |
| 兑换码与分组 | `/api/redemption/*`、`/api/group/*`、`/api/prefill_group/*` | 兑换码、用户组、预填分组 |
| 任务与媒体记录 | `/api/mj/*`、`/api/task/*` | Midjourney 和通用异步任务记录 |
| 模型与供应商元数据 | `/api/vendors/*`、`/api/models/*` | 供应商、模型元数据、上游同步、缺失模型 |
| 模型部署 | `/api/deployments/*` | io.net 部署管理 |
| AI Relay | `/v1/*`、`/v1beta/*`、`/mj/*`、`/suno/*`、`/kling/v1/*`、`/jimeng` | OpenAI/Claude/Gemini/Midjourney/Suno/视频兼容转发 |
| 旧 Dashboard 兼容 | `/dashboard/*`、`/v1/dashboard/*` | OpenAI Dashboard Billing 兼容接口 |
